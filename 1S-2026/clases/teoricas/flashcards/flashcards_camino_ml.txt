¿Cuáles son los pasos del "Camino de ML"?	1. Definición del problema 2. Adquisición de datos 3. Preprocesamiento de los datos 4. Selección de la clase de modelo 5. Algoritmo de optimización 6. Métrica de optimización 7. Model Selection e hiperparámetros 8. Métricas de evaluación 9. Puesta en producción
¿Qué es el Iris dataset?	Dataset clásico de ML con 150 muestras de flores. Tiene 4 features (sepal length, sepal width, petal length, petal width) y 3 clases (Setosa, Versicolor, Virginica).
¿Qué es Data Leakage?	Cuando el modelo entrena con información que no debería tener disponible al momento de predecir en producción. Ej: usar datos del conjunto de test para entrenar o escalar.
¿Qué es la imputación de valores?	Técnica para rellenar datos faltantes. Métodos: media, mediana, moda, nueva categoría (categóricas), o modelos más complejos. Siempre introduce algún sesgo.
¿Qué es un outlier y cómo se trata?	Valor muy alejado del centro de una distribución. Se puede detectar con robust_scale de Scikit-Learn y eliminar usando un threshold de distancia.
¿Qué es Oversampling vs Undersampling?	Técnicas para datasets desbalanceados. Oversampling: genera más muestras de clases minoritarias (SMOTE, ADASYN). Undersampling: elimina muestras de clases mayoritarias (NearMiss). Librería: imbalanced-learn.
¿Qué es Data Augmentation?	Crear más muestras a partir de las originales para un entrenamiento más robusto. Muy usada en imágenes (rotaciones, reflexiones, traslaciones). Librerías: fastai, Albumentations.
¿Qué es Feature Selection y cuáles son sus 3 métodos?	Proceso de seleccionar/descartar columnas. Métodos: 1. Filter Methods (estadísticos, antes del entrenamiento) 2. Embedded Methods (durante el entrenamiento, ej: regularización) 3. Wrapper Methods (después del entrenamiento, ej: RFE)
¿Qué es Feature Extraction?	Crear nuevas features a partir del dataset original para mejorar el poder predictivo. Ej: elevar variables al cuadrado, extraer si una fecha es feriado, agregar fuentes externas.
¿Qué es Feature Scaling?	Transformar columnas para que estén en la misma escala. Min-Max Scaling: escala a un rango preservando distancias. Standard Scaling: media 0 y desviación estándar 1.
¿Cuándo es necesario hacer Feature Scaling?	Cuando el modelo usa valores absolutos (distancias, gradiente descendente). Sin scaling, el modelo puede dar importancia ficticia a features en mayor escala.
¿Qué es One Hot Encoding?	Transformar variables categóricas en columnas binarias (0/1) por cada categoría. Alternativa: Label Encoding (asigna un número entero a cada categoría).
¿Qué es Underfitting vs Overfitting?	Underfitting: modelo muy rígido, no captura patrones, anda mal en train y en test. Overfitting: modelo muy flexible, se sobreajusta al train, generaliza mal en datos nuevos.
¿Cuál es la diferencia entre Training Set, Validation Set y Test Set?	Training Set: datos para entrenar. Validation Set: datos para validar decisiones durante el entrenamiento. Test Set: evaluación final, no debe influenciar el entrenamiento (evitar Data Leakage).
¿Qué es Simple Holdout Set?	Dividir datos en Train (80%) y Test (20%). Muy simple, sin validación. Solo recomendable para prototipos y problemas pequeños.
¿Qué es K-Fold Cross-Validation?	Dividir datos en K particiones. Usar K-1 para entrenar y 1 para validar, rotando. Más robusto que el holdout simple. Valores típicos de K: 5 o 10.
¿Qué es Leave-One-Out Cross-Validation (LOOCV)?	Dejar una sola muestra para validar, iterar sobre todas las muestras. Ventaja: usa casi todos los datos para entrenar. Desventaja: muy costoso computacionalmente.
¿Qué es MSE y cuándo usarlo?	Mean Squared Error: promedio de errores al cuadrado. Penaliza más los errores grandes. Usar cuando equivocarse por mucho es inaceptable. Es derivable, estándar de entrenamiento de muchos métodos.
¿Qué es RMSE?	Root Mean Squared Error: raíz cuadrada del MSE. Igual comportamiento que MSE pero recupera la unidad original. Se compara con MAE para identificar puntos con mucho error.
¿Qué es RMSLE y cuándo usarlo?	Root Mean Squared Log Error: aplica logaritmo antes del RMSE. Mide error relativo (porcentual). Usar cuando importa el error porcentual, no el absoluto. Penaliza más por defecto que por exceso.
¿Qué es MAE y cuándo usarlo?	Mean Absolute Error: promedio de diferencias absolutas. No penaliza tanto los outliers (prioriza la mediana). Usar cuando querés una métrica directamente interpretable.
¿Qué es MAPE y cuándo usarlo?	Mean Absolute Percentage Error: promedio de errores porcentuales. Usar cuando importa el error relativo y necesitás reportar porcentajes. Muy usado en forecasting de ventas. Precaución con valores muy pequeños.
¿Qué es R² y cuál es su rango real?	Coeficiente de determinación: mide qué tan bien anda el modelo vs. predecir la media. R²=1: predicción perfecta. R²=0: tan bueno como el promedio. PUEDE SER NEGATIVO (no va solo de 0 a 1).
¿Qué es la Matriz de Confusión?	Tabla 2x2 para clasificación binaria que cruza valor predicho vs valor real: TP (verdadero positivo), TN (verdadero negativo), FP (falso positivo), FN (falso negativo). Accuracy = (TP+TN)/(TP+FP+TN+FN).
¿Qué es Precision y cuándo usarla?	Precision = TP / (TP + FP). "De los que dije que sí eran, ¿cuántos lo eran?" Usar cuando es muy grave tener falsos positivos. Si no arriesgamos, la precision es alta.
¿Qué es Recall y cuándo usarlo?	Recall = TP / (TP + FN). "De los que sí eran, ¿cuántos detecté?" Usar cuando es muy grave tener falsos negativos. Un clasificador que siempre predice positivo tiene Recall = 1.
¿Qué es F1-Score?	Media armónica entre Precision y Recall: F1 = 2 × (P × R) / (P + R). Usar cuando ambos tipos de error importan en niveles similares. No considera los True Negatives.
¿Qué es la curva ROC y AUC-ROC?	ROC: curva de TPR (Recall) vs FPR variando el threshold. AUC-ROC: área bajo la curva, mide qué tan lejos estamos de un predictor random. No usar cuando las clases están muy desbalanceadas.
¿Qué es la curva PR y AUC-PR?	Curva Precision vs Recall variando el threshold. Preferible a ROC cuando el dataset está muy desbalanceado. Se enfoca solo en la clase positiva.
¿Qué es Best Subset Selection?	Probar todas las combinaciones posibles de features para encontrar la mejor. Garantiza el óptimo global pero es computacionalmente prohibitivo (2^p combinaciones).
¿Qué es Forward Selection vs Backward Selection?	Forward: empieza sin variables e incorpora de a una la que más mejora el modelo. Backward: empieza con todas las variables y elimina de a una. Ambas son estrategias golosas y pueden no encontrar el óptimo global.
¿Qué es la métrica de optimización del modelo?	También llamada loss function o cost function. Es la función que guía al algoritmo de optimización para encontrar los mejores parámetros. No es necesariamente igual a la métrica de evaluación final.
¿Qué es MLOps?	Área que combina ML, ingeniería de software e infraestructura para disponibilizar modelos en producción. Incluye desafíos como data shifts, tiempo de inferencia y disponibilidad de datos en producción.
